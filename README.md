# sudokux — X 数独（对角线数独）生成器与求解器

在标准 9×9 数独规则之上，再要求**两条主对角线**也 1–9 不重复。
纯标准库（argparse / random / sys），无第三方依赖。

## 玩法

- 生成：随机产生一道给定数约 30 格的 X 数独谜题。
- 求解：把谜题文本（9 行，每行 9 个字符，`1-9` 为给定数，`.`/`0` 为空格）喂给 `--solve`。

## 用法

```bash
python -m sudokux                    # 生成一道谜题
python -m sudokux --seed 42          # 固定种子复现
python -m sudokux --givens 35        # 目标给定数（17～81）
python -m sudokux --solution         # 同时打印答案
python -m sudokux --solve puzzle.txt # 求解文件中的谜题
cat puzzle.txt | python -m sudokux --solve   # 从 stdin 求解
python -m sudokux --selftest         # 内置自检
```

## 设计取舍

- **求解器**：MRV（最小剩余值）启发式回溯。X 数独约束比普通数独更紧，
  实测求解毫秒级。
- **生成器**：随机完整解 → 随机顺序逐格挖空，每次挖空后验证仍**唯一解**；
  验证超预算（默认 10 万节点）则保守地恢复该格。因此实际给定数可能
  多于 `--givens` 目标——如实报告实际给定数。
- **"小巧思"**：生成器保证的是"可解且唯一"，而不是"难度分级"；
  想玩难的可以把 `--givens` 调小。

## 验证记录（全部真实执行）

| 检查 | 结果 |
|---|---|
| `py_compile` | 通过 |
| 固定谜题（seed=7/givens=35 生成，35 给定） | 求解器恢复唯一解，`check_solution` 独立验证行/列/宫/双对角线全合法 |
| 10 种子 × 生成（givens=30） | 10/10 可解，解全部通过独立验证器，给定数 ≥ 30 |
| 矛盾谜题（全 5） | 正确返回无解 |
| 文本格式解析往返 | 一致 |
| `--selftest` | 6 通过，0 失败 |

构建中修过的 bug：
1. `generate()` 把 `random.Random` 实例又传给 `full_solution()` 导致
   `TypeError`——`full_solution` 现接受 int 或 Random。
2. **真 bug（自检抓到）**：`count_solutions` 不验证给定数自洽，
   矛盾的满盘输入（如全 5）会被当成"已解决"返回。自检失败后加了
   `is_consistent()` 前置检查，不自洽直接返回 0 解。

## 已知局限

- 生成谜题**不做难度分级**，只是"唯一解"级别。
- 挖空验证有节点预算，极少数情况下实际给定数会多于目标（保守恢复）。
- 求解 `--solve` 只返回找到的第一个解；多解谜题不会提示。
- 纯文本界面，无交互式填涂。
- 需要 Python 3.10+。
